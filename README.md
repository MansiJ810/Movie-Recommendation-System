# *Movie-Recommendation-System*
A machine learning project built with Python that suggests movies to users using either Content-Based Filtering (analyzing genres, plot overviews, and tags) or Collaborative Filtering (analyzing user interaction histories and ratings).

# *Features*
* Content-Based Filtering: Matches movies using TF-IDF vectorization and Cosine Similarity to find titles with similar plots and genres.
* Collaborative Filtering: Recommends movies based on patterns from user preferences and rating behaviors.
* Data Preprocessing Pipeline: Cleans text, merges structured datasets, and extracts core features using Pandas.

# *Tech Stack*
* Language: Python
* Data Manipulation: Pandas, NumPy
* Machine Learning & Metrics: Scikit-learn (Cosine Similarity, TF-IDF Vectorizer)
